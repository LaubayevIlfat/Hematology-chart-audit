# Тест-кейс aps-adult-01

Синтетическая история болезни женщины 34 лет с тромбоэмболией лёгочной артерии и тромбозом подвздошно-бедренного сегмента, тройной позитивностью антифосфолипидных антител (антифосфолипидный синдром, две потери беременности, приём комбинированного орального контрацептива): профилактическая доза эноксапарина при ТЭЛА с ухудшением, ривароксабан вместо варфарина при тройной позитивности с рецидивом тромбоза и ТЭЛА, волчаночный антикоагулянт на гепарине, КОК продолжены, падение тромбоцитов на 5-е сутки без оценки гепарин-индуцированной тромбоцитопении, стратификация ТЭЛА не выполнена, нет ревматолога и повтора антител, выписка с I26.9 без антифосфолипидного синдрома. Все данные вымышлены. Кейс не использовался при настройке навыка (нозология новая; смежные кейсы `hit-adult-01`, `ttp-adult-01`).

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: антифосфолипидный синдром и венозная тромбоэмболия, выбор антикоагулянта (прямые пероральные антикоагулянты при тройной позитивности противопоказаны), доза эноксапарина при ТЭЛА, достоверность волчаночного антикоагулянта на гепарине, эстрогены при тромбозе, стратификация ТЭЛА; ловушки (КТ-ангиография, перевод в ОРИТ, тромболизис не показан, коррекция схемы на Д+9).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.1: 7 значимых (З1 №1, №2; З2 №3–6, №8) и 4 незначимые находки (№9–12), ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 6 из 7, класс совпал не менее чем у 5 из 7, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом, ревматологом и акушером-гинекологом.
