# Тест-кейс apl-adult-02

Синтетическая история болезни женщины 34 лет с острым промиелоцитарным лейкозом (t(15;17), PML-RARA+, промежуточный риск) и коагулопатией: третиноин отложен до ПЦР и назначен вдвое ниже дозы, коррекция тромбоцитов и фибриногена после внутричерепного кровоизлияния, ЦВК при тромбоцитах 38, мышьяка триоксид при QTc 468–520 и гипокалиемии, дифференцировочный синдром без профилактики и со стартом дексаметазона с задержкой (ОРИТ), нет теста на беременность, выписка с потерей варианта ОПЛ. Все данные вымышлены. Второй кейс по ОПЛ: нозология уже была в наборе (`apl-adult-01`), и правила навыка (в том числе о QTc при мышьяке) настраивались по нему, поэтому по нозологии этот кейс не независим; независимы его конкретные записи и сочетание ошибок.

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей (фибриноген, QTc, калий, лейкоциты, вес), времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: острый промиелоцитарный лейкоз (неотложный старт третиноина без ожидания ПЦР, коагулопатия, ДВС), внутричерепное кровоизлияние как реализованное осложнение задержки, дифференцировочный синдром (профилактика преднизолоном, поздний дексаметазон), безопасность мышьяка триоксида (QTc, калий, магний, QT-препараты, пороги паузы), тератогенность ретиноида (β-ХГЧ), выписка с потерей варианта; ловушки (схема без антрациклинов, дозировка мышьяка, КТ, ОРИТ).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.1: 9 значимых (З1 №1, №2, №4, №5; З2 №3, №6–9) и 4 незначимые находки (№10–13), ловушки, ожидаемая оценка тактики, системность, решения эксперта. Не загружать вместе с историей.

Критерий приёмки (9 значимых): найдено не менее 8 из 9, класс совпал не менее чем у 7 из 9, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
