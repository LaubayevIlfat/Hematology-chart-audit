# Тест-кейс hsct-adult-01

Синтетическая история болезни взрослого пациента после аллогенной ТГСК (ОМЛ с NPM1 и FLT3-ITD, первая ремиссия), нелетальный исход. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: аллогенная трансплантация (иммуносупрессия, РТПХ), мониторинг такролимуса и нейротоксичность (PRES), взаимодействие позаконазола с такролимусом, ЦМВ (профилактика и мониторинг), задержка терапии острой РТПХ, облучённые компоненты, HBV и пневмоцистная профилактика, выписка после ТГСК.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики («субоптимальна» или «приемлема») и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
