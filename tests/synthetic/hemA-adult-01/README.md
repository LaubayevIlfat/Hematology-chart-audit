# Тест-кейс hemA-adult-01

Синтетическая история болезни мужчины 34 лет с тяжёлой гемофилией A без ингибитора и гематомой подвздошно-поясничной мышцы с компрессионной нейропатией бедренного нерва: диклофенак внутримышечно с гематомой ягодицы, первая доза фактора VIII через 4 часа, доза и интервал ниже плана, уровень фактора и ингибитор не контролировались, задержка при нейропатии со стойким парезом, преждевременная отмена с ростом гематомы, выписка с диклофенаком. Все данные вымышлены. Кейс не использовался при настройке навыка.

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей (прирост фактора 18% при ожидаемом около 49%), времени введения, расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: гемофилия A у взрослого без ингибитора (ранее только ребёнок с ингибитором на эмицизумабе); дозирование фактора VIII по массе (50 МЕ/кг для 100%) и интервал по периоду полувыведения; расчёт ожидаемого прироста и ингибитор при низком приросте; противопоказанное назначение при гемофилии (НПВП, внутримышечные инъекции, З1 при реализованной гематоме); задержка при остром неврологическом симптоме с зафиксированным стойким дефицитом (З1 при стойком вреде, граница с правилом З2); срок заместительной терапии; ловушки (рекомбинантный фактор, МРТ и хирург, отсутствие трансфузии, ДДАВП не назначался).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 6 значимых (З1 №1, №2, №7; З2 №5, №6, №8; №3 и №4 объединены с №2) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 5 из 6, класс совпал не менее чем у 4 из 6, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.

Версия ключа 1.1: после прогонов 1–3 внесены решения эксперта (объединение задержки первой дозы, дозы и интервала в одну З1, №6 — З2, №7 — З1); подробности в конце `_answer_key/answer_key.md` и в `comparison.md`.
