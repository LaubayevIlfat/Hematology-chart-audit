# Тест-кейс aml-child-01

Синтетическая история болезни девочки 2 лет с острым миелоидным лейкозом (FAB M2) и гиперлейкоцитозом 180·10⁹/л (масса 13 кг, площадь тела 0,57 м²): даунорубицин 60 мг на введение вместо 34 мг (60 мг/м²) с кардиотоксичностью (фракция выброса 38%), антибиотик при фебрильной нейтропении через 6 часов с септическим шоком, люмбальная пункция при тромбоцитах 16 без трансфузии, профилактика синдрома лизиса ниже плана, не исследованы кариотип, FLT3, NPM1, KMT2A и HLA, нет противогрибковой профилактики, костный мозг Д+28 не исследован, выписка с C95.9 без плана консолидации и ТГСК. Все данные вымышлены. Кейс не использовался при настройке навыка (нозология новая для детского профиля; смежный взрослый кейс `aml-adult-01`).

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: ОМЛ у ребёнка раннего возраста, расчёт доз химиотерапии по площади тела (ошибка мг/м² и мг), кардиотоксичность антрациклинов, фебрильная нейтропения (время до антибиотика), профилактика синдрома лизиса при гиперлейкоцитозе, люмбальная пункция при тромбоцитопении; ловушки (лейкаферез, облучённые компоненты, цефепим как препарат выбора).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.0: 8 значимых (З1 №1, №2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, детский профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке детским онкогематологом и кардиологом.
