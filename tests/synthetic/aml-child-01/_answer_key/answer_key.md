# Ключ к тест-кейсу aml-child-01 (НЕ загружать вместе с историей)

Кейс не использовался при настройке навыка (нозология новая для детского профиля; смежный взрослый кейс `aml-adult-01`); клинические ориентиры написаны автором и подлежат проверке гематологом (детским онкогематологом) и кардиологом.
