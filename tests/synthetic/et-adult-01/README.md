# Тест-кейс et-adult-01

Синтетическая история болезни женщины 31 года с эссенциальной тромбоцитемией JAK2+ (тромбоз воротной вены в анамнезе, высокий риск) и беременностью 20 недель: гидроксимочевина при беременности вместо интерферона с отставанием роста плода и маловодием, нет профилактики эноксапарином с тромбозом глубоких вен голени, ацетилсалициловая кислота 500 мг вместо 75–100 мг, профилактическая доза НМГ при тромбозе, не исследованы антифосфолипидные антитела и нет допплерометрии, нет консультации акушера в день поступления, редкий контроль ОАК при циторедукции, выписка с D75.1, варфарином и гидроксимочевиной. Все данные вымышлены. Кейс не использовался при настройке навыка (нозология новая; смежные МПН: `pv-adult-01`, `mf-adult-01`).

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей (тромбоциты, лейкоциты, УЗИ плода), времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: миелопролиферативная неоплазия в беременности (противопоказание гидроксимочевины, интерферон, аспирин и НМГ), тератогенное назначение с реализованным вредом для плода (З1), пропущенная тромбопрофилактика с тромбозом (З1), лечебная и профилактическая доза НМГ, совместное ведение с акушером, выписка с противопоказанным варфарином; ловушки (госпитализация, аспирин как класс, УЗДГ, эноксапарин после тромбоза).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.1: 8 значимых (З1 №1, №2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом и акушером-гинекологом.
