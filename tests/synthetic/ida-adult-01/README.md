# Тест-кейс ida-adult-01

Синтетическая история болезни мужчины 68 лет с тяжёлой железодефицитной анемией (Hb 68, MCV 63) и подозрением на желудочно-кишечную кровопотерю (тёмный стул, скрытая кровь), ИБС со стентом и двойной антитромбоцитарной терапией, ХСН (фракция выброса 40%): три дозы эритроцитов подряд без диуретика с отёком лёгких, внутривенное железо 1500 мг за 15 минут с гипотонией, колоноскопия не проведена, ферритин и другие показатели до железа не исследованы, ИПП не назначен, антитромбоцитарная терапия без решения кардиолога, дублирование железа, выписка с D50.9 без плана обследования ЖКТ. Все данные вымышлены. Кейс не использовался при настройке навыка (нозология новая; смежные кейсы `b12-adult-01`, `thal-child-01`).

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: железодефицитная анемия с обязательным поиском источника кровопотери, переливание эритроцитов при ХСН (перегрузка объёмом), внутривенные препараты железа (доза, скорость, реакция), совместное ведение с кардиологом (двойная антитромбоцитарная терапия) и гастропротекция; ловушки (показание к трансфузии, ЭГДС, тромбоцитоз, потеря массы после диуретика).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.0: 8 значимых (З1 №1, №2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом, кардиологом и гастроэнтерологом.
