# Тест-кейс vwd-adult-01

Синтетическая история болезни женщины 28 лет с болезнью Виллебранда типа 2B перед плановой лапароскопической цистэктомией: десмопрессин при типе 2B с тромбоцитопенией и послеоперационным кровотечением, нет предоперационной заместительной терапии и исходных уровней ФВ/ФVIII, нет консультации гематолога, сниженная транексамовая кислота, кеторолак при кровотечении, запоздалый контроль ОАК, выписка с D69.9 и ибупрофеном. Все данные вымышлены. Кейс не использовался при настройке навыка.

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей (тромбоциты 140 → 38), времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: болезнь Виллебранда тип 2B (противопоказание десмопрессина), периоперационная подготовка при наследственной коагулопатии, транексамовая кислота и концентрат ФВ/ФVIII по весу, НПВП при кровотечении (З1 по правилу), выписка с потерей варианта и противопоказанной рекомендацией; ловушки (показания к операции, консервативная тактика, парацетамол, отсутствие тромбоцитарной массы).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, №4; З2 №2, №3, №5–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
