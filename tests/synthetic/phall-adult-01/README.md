# Тест-кейс phall-adult-01

Синтетическая история болезни женщины 29 лет с Ph-положительным В-ОЛЛ (BCR::ABL1 p190, гиперлейкоцитоз): преднизолон, винкристин и дазатиниб в индукции, плевральный выпот 3 степени на дазатинибе при продолжении препарата, желудочное кровотечение на кеторолаке при тромбоцитопении, нейропатия на винкристине. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: Ph-положительный ОЛЛ взрослого, ТКИ второго поколения (дазатиниб) в индукции: плевральный выпот при продолжении препарата, взаимодействие с ИПП, НПВП при тромбоцитопении и ТКИ, ожидание кариотипа при положительной ПЦР BCR::ABL1 (проверка нового правила об ожидании подтверждающего исследования: З2 без реализованного ухудшения), максимальная доза винкристина, ЛП и ИТ-профилактика после подъёма тромбоцитов, BCR::ABL1 на Д+28, ТГСК с здоровой сестрой; ловушки (ЦВК с коррекцией, ЭКГ и QTc, антибиотик в срок, отсрочка ЛП при низких тромбоцитах, расхождение массы при единой площади тела).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` (v1.1) — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
