# Тест-кейс mds-adult-lethal-01

Синтетическая история болезни пациента 72 лет с миелодиспластическим синдромом с избытком бластов 2 (очень высокий риск по IPSS-R), азацитидин + венетоклакс, летальный исход (Д+19), заключение ПАО в материалах. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: второй летальный случай (раздел 5, ПАО, структура причин смерти, категория исхода, предотвратимость, сопоставление клинического и ПА диагнозов), МДС и гипометилирующая терапия с венетоклаксом off-label, известная колонизация ESBL при выборе эмпирической антибиотикотерапии, отсутствие противогрибковой профилактики и позднее обследование при затяжной нейтропении, паллиативный подход, посмертный эпикриз, не согласованный с ПАО.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` (v1.1) — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики, структура раздела 5 и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, применён раздел 5 с заполненной структурой, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
