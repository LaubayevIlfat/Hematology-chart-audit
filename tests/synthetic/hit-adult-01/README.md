# Тест-кейс hit-adult-01

Синтетическая история болезни женщины 62 лет с гепарин-индуцированной тромбоцитопенией (4T = 8 баллов) и тромбозом глубоких вен после эндопротезирования тазобедренного сустава: лечебный эноксапарин продолжен 5 суток до результата антител (ТЭЛА), диагноз не заподозрен, тромбоцитарная масса без кровотечения, варфарин при тромбоцитах менее 150 с некрозом кожи, АЧТВ при аргатробане раз в сутки, промывание ЦВК гепарином, недодоза ривароксабана, выписка с рекомендацией эноксапарина. Все данные вымышлены. Кейс не использовался при настройке навыка.

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей (падение тромбоцитов с 245 до 52), времени введения и взятия анализов, расхождению плана и листа назначений и по отсутствию действия в листе.

Новое по сравнению с другими кейсами: гепарин-индуцированная тромбоцитопения — первый кейс на антикоагулянтной и тромботической проблематике (ранее только отдельные эпизоды в ПНГ, ЭПГ и АИГА); шкала 4T и отмена всех гепаринов без ожидания антител (правило об ожидании подтверждающего исследования, З1 при реализованной ТЭЛА); скрытая экспозиция гепарина (промывание катетеров); противопоказанные назначения (тромбоцитарная масса, варфарин при тромбоцитопении с некрозом кожи — З1); мониторинг аргатробана по АЧТВ; недодоза ривароксабана; выписка с потерей варианта; ловушки (аргатробан как препарат выбора, витамин K, КТ-ангиография).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, №4; З2 №2, №3, №5–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
