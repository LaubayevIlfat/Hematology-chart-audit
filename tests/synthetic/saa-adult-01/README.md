# Тест-кейс saa-adult-01

Синтетическая история болезни молодой взрослой пациентки с тяжёлой апластической анемией (D61.3), иммуносупрессивная терапия (л-АТГ + циклоспорин), нелетальный исход. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: апластическая анемия (не опухоль), оценка тактики по выбору первой линии (ТГСК против ИСТ при HLA-идентичном родственном доноре), лекарственные взаимодействия и мониторинг уровня циклоспорина, сывороточная болезнь после АТГ, переливания от потенциального донора ТГСК, обследование до ИСТ (ПНГ, цитогенетика, DEB, беременность).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1; З2 №2–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики («субоптимальна») и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
