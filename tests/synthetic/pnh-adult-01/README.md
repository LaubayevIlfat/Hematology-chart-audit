# Тест-кейс pnh-adult-01

Синтетическая история болезни молодой женщины с пароксизмальной ночной гемоглобинурией (ПНГ, D59.5), гемолитический криз, начало терапии экулизумабом, нелетальный исход. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: терапия ингибитором комплемента (менингококкемия при начале без вакцинации и антибиотикопрофилактики), тромботический риск при ПНГ (синдром Бадда — Киари без профилактики), задержка 2-й дозы экулизумаба, пигментная нефропатия, выписка без профилактики инфекций, фолиевая кислота, предтерапевтический минимум.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики («приемлема» или «субоптимальна») и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
