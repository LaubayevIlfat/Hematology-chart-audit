# Тест-кейс cml-adult-01

Синтетическая история болезни взрослого пациента с хроническим миелолейкозом, хроническая фаза (C92.1), гиперлейкоцитоз с лейкостазом, циторедукция и нилотиниб, нелетальный исход. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: хронический миелолейкоз (миелопролиферативное заболевание), гиперлейкоцитоз и лейкостаз (сроки циторедукции, стойкий вред зрению), выбор ингибитора тирозинкиназ при сердечно-сосудистом риске, QTc и взаимодействия нилотиниба (ИПП, ондансетрон, приём с едой), мониторинг BCR::ABL1.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики («субоптимальна») и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
