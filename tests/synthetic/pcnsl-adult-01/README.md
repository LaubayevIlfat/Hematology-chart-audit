# Тест-кейс pcnsl-adult-01

Синтетическая история болезни мужчины 61 года с первичной диффузной В-крупноклеточной лимфомой ЦНС и ХБП 3б, получающего R-HD-MTX: метотрексат 3,5 г/м² при клиренсе креатинина около 44 мл/мин без ощелачивания мочи (острое повреждение почек), лейковорин начат через 40 часов без эскалации при 48-часовой концентрации 4,8 мкмоль/л (мукозит 4 степени, нейтропения), антибиотик при фебрильной нейтропении через 7,5 часа (гипотония), глюкокортикоиды до биопсии, не исследованы вирусы и не завершено стадирование, выписка без диагноза лимфомы и без условий следующего цикла. Все данные вымышлены. Кейс не использовался при настройке навыка (нозология новая; смежные кейсы `mm-adult-01`, `dlbcl-adult-01`).

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: высокодозный метотрексат (клиренс креатинина, ощелачивание, мониторинг концентрации, лейковориновое спасение), первичная лимфома ЦНС, стероиды до биопсии; ловушки (выбор схемы, левитирацетам, цефепим, трансфузия тромбоцитов, Г-КСФ после выведения, глюкарпидаза ниже порога).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.1: 7 значимых (З1 №1–3; З2 №4–7) и 4 незначимые находки, ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 6 из 7, класс совпал не менее чем у 5 из 7, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Решения эксперта после прогонов 1–3 внесены в ключ v1.1 и `comparison.md`.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом-онкологом и нефрологом.
