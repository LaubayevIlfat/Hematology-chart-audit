# Тест-кейс g6pd-child-01

Синтетическая история болезни мальчика 6 лет с острым внутрисосудистым гемолизом на ко-тримоксазоле и недиагностированным дефицитом Г6ФД: ко-тримоксазол продолжен в стационаре около 31 часа, при SpO2 91% без со-оксиметрии введён противопоказанный метиленовый синий (усиление гемолиза, ОПП), эритроцитная масса начата через 7 ч 30 мин от показания (шок, ОРИТ), ложно нормальная активность Г6ФД в остром гемолизе принята как «дефицит исключён», не проведена проба Кумбса, не назначена фолиевая кислота, выписка без диагноза дефицита Г6ФД, карты запретов и обследования родственников. Все данные вымышлены. Кейс не использовался при настройке навыка (нозология новая; смежные кейсы `aiha-adult-01`, `hs-child-01`).

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: дефицит Г6ФД и лекарственный гемолиз, противопоказанные препараты (метиленовый синий, расбуриказа, сульфаниламиды), ложно нормальный тест Г6ФД в остром гемолизе, срок трансфузии при критической анемии; ловушки (отказ от трансфузии при Hb 62 без нарушений гемодинамики, выбор цефиксима, гидратация, ОРИТ).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.1: 7 значимых (З1 №1–4; З2 №5–7) и 4 незначимые находки, ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 6 из 7, класс совпал не менее чем у 5 из 7, детский профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке детским гематологом.
