# Тест-кейс apl-adult-01

Синтетическая история болезни взрослой пациентки с ОПЛ (C92.4), индукция ATRA + триоксид мышьяка, выписана с улучшением. Все данные вымышлены. Кейс не использовался при настройке навыка (в отличие от `aml-adult-01`).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых и 4 незначимые находки, ловушки, ожидаемая оценка и системные цепочки. Не загружать вместе с историей.

Критерий приёмки по PRD v0.6 (критерий 8): найдено не менее 7 из 8 значимых ошибок, класс совпал не менее чем у 6 из 8, нет выдуманных ссылок и утечек идентификаторов.

Клинические данные (дозы, сроки, пороги) написаны автором кейса и подлежат проверке врачом-экспертом перед использованием кейса как эталона.

Версии: chart 1.1 (добавлены признаки токсичности третиноина, отделимые от головной боли при коагулопатии), ключ 1.1 (пункт 6 — З1 по решению эксперта). Прогоны 1 и 2 сделаны на chart 1.0 и ключе 1.0.
