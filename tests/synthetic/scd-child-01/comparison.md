Замечания агента о правилах: граница З1/З2 для гидроксимочевины при нейтропении, присутствовавшей уже при поступлении (выбран З2); для З1-01 нет разграничения «осложнение вызвано режимом, но сопровождается прогрессированием основного заболевания»; для кислорода и фенотипа неясно, достаточно ли значения показателя при выдержках; нет рубрики для острого грудного синдрома и гемоглобинопатий в `sources.md`; закрытый список этапа лечения без варианта «острое осложнение хронического заболевания»; определение «тактики» исключает раздел 4, где основные дефекты кейса.

2. **ТКД (№7):** оставить отдельной З2 в ключе (ежегодный скрининг просрочен) или признать допустимым объединение с выпиской, как сделал агент?
3. **Гидроксимочевина при нейтропении, существовавшей при поступлении (№6):** оставить З2 (ожидаемая токсичность, нейтропения купировалась) или поднять до З1 при лихорадке и ОРИТ?
4. **Незначимый №12 (код пневмонии не указан):** оставить в ключе или заменить на другое (в истории без раздела «Внутренние отметки» код D57.0 без J18 — слабый признак)?
5. **Кислород при SpO2 ниже порога без назначения (№2):** закрепить правило (при SpO2 ниже порога без записи кислорода — З2 по правилу присутствующих данных)?
