# Тест-кейс scd-child-01

Синтетическая история болезни мальчика 9 лет с серповидноклеточной анемией (HbSS) на гидроксимочевине и острым грудным синдромом: избыточная инфузия (140 мл/ч) с отёком лёгких и переводом в ОРИТ, кислород поздно, цефтриаксон без макролида, трансфузия до Hb 118 без фенотипа и скрининга антител, гидроксимочевина при нейтропении, просроченная транскраниальная допплерография, выписка без плана. Все данные вымышлены. Кейс не использовался при настройке навыка.

**Отличие формата.** Эта версия истории подготовлена без раздела «Внутренние отметки», который в кейсах 1–20 перечислял заложенные дефекты (замечание агентов слепых прогонов). Находки выводятся только из записей истории (лист назначений, дневники, лаборатория, трансфузия), поэтому показатели по кейсу честнее показателей по кейсам 1–20 и сопоставимы с ними лишь с оговоркой. В связи с этим исчезли явные записи об отсутствии действий; пропуски видны по значениям показателей и по отсутствию действия в листе назначений («присутствующие данные не считать отсутствием записи»).

Новое по сравнению с другими кейсами: серповидноклеточная анемия и острый грудной синдром у ребёнка; перегрузка объёмом при гидратации; цель гемоглобина при трансфузии; фенотип-совместимые компоненты; гидроксимочевина при нейтропении; ежегодная ТКД; ловушки (антибиотик в срок, ОРИТ в срок, морфин с мониторингом, трансфузия по показаниям, профилактика пенициллином).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` (v1.1) — 8 значимых (З1 №1; З2 №2–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, детский профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
