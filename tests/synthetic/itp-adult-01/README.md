# Тест-кейс itp-adult-01

Синтетическая история болезни взрослой пациентки с первичной иммунной тромбоцитопенией (D69.3), тяжёлый геморрагический синдром, нелетальный исход. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: доброкачественное заболевание системы крови (ИТП), безопасность препаратов крови (иммуноглобулин при известном дефиците IgA), противопоказанные при тромбоцитопении назначения (НПВП, внутримышечные инъекции) с отделимым вредом (гематома), задержка начала терапии при тяжёлом кровотечении, меноррагия, нейровизуализация при головной боли на фоне тромбоцитопении, диагноз исключения.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики («приемлема» или «субоптимальна») и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
