## Резюме
- Профиль: взрослый. Первичная ИТП, D69.3. Исход: выписана с улучшением (Д+14).
- Счётчик З1 / З2 / Н = 2 / 5 / 4. Оценка тактики: субоптимальна.
- Системность: цепочка «головная боль без оценки → кеторолак в/м → гематома → трансфузия»; нет чек-листа перед иммуноглобулином; нет алгоритма поступления при ИТП; нет практики ДСМ-320.
