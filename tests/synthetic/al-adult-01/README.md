# Тест-кейс al-adult-01

Синтетическая история болезни мужчины 62 лет с системным AL-амилоидозом (λ) с поражением сердца и почек, получающего Dara-CyBorD: дексаметазон 40 мг при NYHA III с отёком лёгких и ОРИТ, дигоксин при кардиальном амилоидозе с интоксикацией и ОРИТ, типирование амилоида и стадирование Mayo не выполнены, бортезомиб в полной дозе при нейропатии 2 степени с переходом в 3 степень, нет профилактики тромбоза (тромбоз вен голени) и ацикловира (опоясывающий лишай), выписка без AL-амилоидоза и плана. Все данные вымышлены. Кейс не использовался при настройке навыка (нозология новая; смежные кейсы `mm-adult-01`, `wm-adult-01`).

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, расхождению плана и листа назначений и записям «не исследовался».

Новое по сравнению с другими кейсами: AL-амилоидоз с поражением сердца и почек, дозирование дексаметазона и запрещённые препараты при кардиальном амилоидозе, типирование амилоида и стадирование Mayo 2012, нейропатия на бортезомибе и снижение дозы, тромбопрофилактика при нефротическом синдроме; ловушки (выбор схемы, отмена эналаприла, ОРИТ, лечебная антикоагуляция, отмена бортезомиба).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.0: 8 значимых (З1 №1, №2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом-онкологом и кардиологом.
