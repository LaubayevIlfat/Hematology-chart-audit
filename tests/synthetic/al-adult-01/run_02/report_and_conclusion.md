Показание «урежение синусовой тахикардии» неоправданно: тахикардия при ограниченном ударном объёме компенсаторна, ФВ сохранна. Класс З1 (реализованное осложнение, прямо вызванное действием).
- Уверенность: высокая по нарушению плана и по факту осложнения; средняя по внешнему эталону. Примечание: уровень 3,2 нг/мл через не более 47 ч без записанной нагрузочной дозы нетипично высок (см. «Вопросы лечащему врачу»); на класс не влияет.
- Как следовало поступить: не назначать препарат, запрещённый планом; искать причину тахикардии (объём, анемия, ритм), привлечь кардиолога; при необходимости урежения использовать допустимые для амилоидоза подходы по решению кардиолога.

**З1-02. Дексаметазон 40 мг вместо 20 мг при сердечной недостаточности; острый отёк лёгких (раздел 3)**

**З1-03. Бортезомиб полной дозой при болевой нейропатии; нейропатия 3 степени (раздел 3)**

- Как следовало поступить: оценка нейропатии по CTCAE перед каждым введением (особенно при исходных симптомах), снижение дозы на Д+25 по плану, неврологический осмотр и противоболевая терапия.

**З2-01. До терапии не выполнены типирование амилоида, тропонин и деформация миокарда (раздел 2)**
- Выявлено: план (Д0) требует до начала: типирование амилоида (ИГХ или масс-спектрометрия), стадирование по Mayo 2012 (NT-proBNP, тропонин T, разность свободных цепей), ЭхоКГ с продольной деформацией. - Уверенность: средняя (по представленным материалам).
- Как следовало поступить: тропонин и GLS до первого введения, типирование направить сразу, не откладывая терапию, зафиксировать стадию.

**З2-03. Рекомендации при выписке неполные и содержат потенциальную ошибку по антикоагулянту (раздел 1, значимая)**

- Уверенность: средняя (внутренний анализ записей); низкая по элементу ривароксабана.
- Как следовало поступить: указать основной диагноз и осложнения, план лечения и сроки контроля гематологом, срок и режим антикоагуляции.

Цепочки ошибок
- Цепочка 1 (кардиологическая): дексаметазон 40 мг на Д+4, отсутствие ежедневного контроля массы и баланса → острый отёк лёгких Д+6 → тахикардия → дигоксин вопреки плану Д+7 → интоксикация и гиперкалиемия Д+9 → второй перевод в ОРИТ. Звено, где цепочку можно было прервать: введение дексаметазона по плану на Д+4 или отказ от дигоксина на Д+7 (запрет в плане).
- Цепочка 2 (нейротоксичность): исходные симптомы нейропатии не оценены → «жалоб нет» (Д+20, Д+21) → боль на Д+25 → дозы без снижения на Д+25 и Д+32 → нейропатия 3 степени и отмена препарата Д+39. Звено: снижение дозы на Д+25 по плану.
- Цепочка 3 (профилактика): гипоальбуминемия 17–19 г/л и бортезомиб без профилактики ТГВ и ацикловира → тромбоз Д+38 и лишай Д+45 → выписка без плана терапии и наблюдения гематолога. Звено: назначение профилактических пунктов плана на Д+4.
- Цепочка 4 (стадирование): нет тропонина, типирования и GLS → интенсивность не адаптирована к риску. Звено: тропонин и GLS до Д+4.

Влияние на исход: повлияли З1-01–З1-05 (реализованные осложнения; на смерть не влияли, пациент выписан живым). З2-01–З2-03 — риски без реализации. Н не влияют.

Рекомендации по устранению причин
- Отделению: чек-лист «перед первым введением» (тропонин, GLS, HBV, ВИЧ/HCV, типирование направлено, профилактика ТГВ, ацикловир) и «перед каждым введением» (CTCAE нейропатии, масса, баланс, электролиты); сверка листа назначений с планом вторым лицом (врач или клинический фармацевт) для схем с дозами по условиям (сердечная недостаточность, нейропатия).
- Системе: закрепить регламентом перечень запрещённых препаратов при AL-амилоидозе сердца (дигоксин, блокаторы кальциевых каналов, бета-блокаторы) в виде предупреждения в МИС; обеспечить доступ к типированию амилоида; шаблон выписного эпикриза для онкогематологии (диагноз, ответ, план, срок антикоагуляции).
