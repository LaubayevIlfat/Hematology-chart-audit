# Тест-кейс b12-adult-01

Синтетическая история болезни женщины 58 лет с тяжёлой витамин-B12-дефицитной анемией и неврологическими проявлениями (Hb 52, MCV 124, B12 62; метформин и омепразол много лет): фолиевая кислота вместо B12 первые двое суток, цианокобаламин вдвое ниже плана, трансфузия двух доз за 4 часа с отёком лёгких, калий не контролировался (гипокалиемия 2,4, желудочковая тахикардия, ОРИТ), невролог и МРТ не выполнены, железо при ферритине 480, причина не исследована, выписка без схемы поддержки. Все данные вымышлены. Кейс не использовался при настройке навыка.

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей (прочерки в таблице калия), расхождению плана и листа назначений, времени введения и отсутствию действия в листе.

Новое по сравнению с другими кейсами: мегалобластная (B12-дефицитная) анемия — первая неонкологическая нетрансфузионная анемия с неврологическими проявлениями; фолиевая кислота без B12; задержка старта витамина; недодоза по плану; гипокалиемия при старте терапии (З1 при реализованной желудочковой тахикардии); трансфузия при хронической анемии (скорость и объём, отёк лёгких); железо без показания при ферритине 480 (правило из полицитемии); причина дефицита (препараты, этиология); выписка при пожизненной терапии; ловушки (цианокобаламин как метод, ретикулоцитарный криз, ОРИТ и калий, отсутствие костного мозга).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №3–4; З2 №1–2, №5–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.

Версия ключа 1.1: после прогонов 1–3 внесены решения эксперта (фолиевая кислота и задержка B12 — З2, плановое обследование причины — З2, диабет E10.9 входит в выписку, новый №11); подробности в конце `_answer_key/answer_key.md` и в `comparison.md`.
