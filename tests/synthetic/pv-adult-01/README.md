# Тест-кейс pv-adult-01

Синтетическая история болезни мужчины 61 года с истинной полицитемией (JAK2 V617F, высокий риск тромбозов): гематокрит 56%, кровопускания не проводятся, аспирин отменён и не возобновлён, назначено железо, ишемический инсульт на Д+5. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: миелопролиферативное заболевание (Ph-негативная МПН) и контроль гематокрита; пропущенная антитромботическая профилактика с реализованным тромбозом; железо при ИП; задержка при остром неврологическом симптоме; непереносимость гидроксимочевины и выбор второй линии; профилактика ТГВ при постельном режиме; НПВП при антиагреганте; выписка без аспирина и целевого гематокрита; ловушки (кровопускание с возмещением объёма, тромбоциты 640–700 без ограничений аспирина, отсрочка биопсии).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` (v1.1) — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
