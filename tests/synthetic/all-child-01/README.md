# Тест-кейс all-child-01

Синтетическая история болезни ребёнка 6 лет с В-линейным ОЛЛ высокого риска, индукция по протоколу семейства BFM, выписан с улучшением. Все данные вымышлены. Кейс не использовался при настройке навыка.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых и 4 незначимые находки, ловушки, ожидаемая оценка и системные цепочки. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8 значимых ошибок, класс совпал не менее чем у 6 из 8, возрастной профиль определён верно (детский), нет выдуманных ссылок и утечек идентификаторов.

Клинические значения (дозы, объёмы, возрастные нормы) написаны автором кейса и подлежат проверке педиатром-гематологом перед использованием кейса как эталона.
