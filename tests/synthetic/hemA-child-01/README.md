# Тест-кейс hemA-child-01

Синтетическая история болезни ребёнка 9 лет с тяжёлой гемофилией A с ингибитором на профилактике эмицизумабом, кровоизлияние в подвздошно-поясничную мышцу, нелетальный исход. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: гемофилия с ингибитором и таргетная профилактика (эмицизумаб), лекарственное взаимодействие аПК с эмицизумабом (тромботическая микроангиопатия), задержка гемостатической терапии при кровоизлиянии, НПВП при гемофилии, осложнение со стороны нерва, выписные рекомендации, повторяющие риск; второй детский профиль после ОЛЛ.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики («субоптимальна» или «не соответствует») и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, детский профиль определён верно, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
