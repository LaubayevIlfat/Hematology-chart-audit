# Тест-кейс itp-child-01

Синтетическая история болезни девочки 5 лет с впервые диагностированной тяжёлой иммунной тромбоцитопенией (тромбоциты 6), носовым кровотечением и нетипичными признаками: ибупрофен при тромбоцитопении с усилением кровотечения, иммуноглобулин по завышенной массе из листа назначений, головная боль и рвота без нейровизуализации, преднизолон 21 день вместо короткого курса, костный мозг после стероидов, выписка без отсрочки живых вакцин. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: детская ИТП (предыдущий кейс ИТП был взрослым), НПВП при тромбоцитопении (проверка нового правила: З1 при реализованном кровотечении), расхождение массы с весозависимой дозой иммуноглобулина (контраст с правилом о массе без весозависимых доз: З2), задержка костного мозга при нетипичной ИТП, длительность стероида, скорость инфузии иммуноглобулина, вакцинация после иммуноглобулина; ловушки (нет трансфузии тромбоцитов, ЛП не выполнена при тромбоцитах 38, антинуклеарные антитела как желательное обследование).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` (v1.1) — 7 значимых (З1 №1; З2 №2–7; №8 объединён с №2) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки (v1.1, 7 значимых): найдено не менее 6 из 7, класс совпал не менее чем у 5 из 7, детский профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
