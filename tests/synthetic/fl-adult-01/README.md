# Тест-кейс fl-adult-01

Синтетическая история болезни женщины 58 лет с фолликулярной лимфомой (объёмное образование 9 см, В-симптомы), получающей R-B: не исследованы HBsAg и анти-HBc до ритуксимаба с реактивацией гепатита B и острой печёночной недостаточностью, ритуксимаб 300 мг/ч с начала без премедикации с инфузионной реакцией 3 степени и ОРИТ, стадирование и трепанобиопсия не выполнены, тонкоигольная пункция вместо эксцизионной биопсии, 2-й курс полной дозой при нейтрофилах 0,6, нет ацикловира и ко-тримоксазола, ритуксимаб 800 мг вместо 660 мг, выписка с C85.9 и 3-м курсом без контроля HBV. Все данные вымышлены. Кейс не использовался при настройке навыка (нозология новая; смежные кейсы `wm-adult-01`, `dlbcl-adult-01`, `cll-adult-01`).

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: индолентная фолликулярная лимфома, скрининг HBV перед ритуксимабом и реактивация гепатита B (З1), скорость и премедикация первой инфузии ритуксимаба, пороги бендамустина по цитопении, полное стадирование и эксцизионная биопсия; ловушки (показание к лечению, остановка инфузии, энтекавир при реактивации, надир нейтрофилов).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.1: 8 значимых (З1 №1, №2, №5; З2 №3, №4, №6–8) и 3 незначимые находки, ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Решения эксперта после прогонов 1–3 внесены в ключ v1.1 и `comparison.md`.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом-онкологом и гепатологом.
