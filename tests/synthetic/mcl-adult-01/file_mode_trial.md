# Пробный запуск файлового режима на mcl-adult-01

Цель: проверить `references/file-mode.md` и `tools/prepare_case.py` до реальных данных. Навык и ключ во время запуска не менялись; рабочие файлы лежали в `cases/trial-mcl/` (не коммитятся).

## Как проводился

1. `chart.md` разрезан на 3 документа Word: (1) поступление и обследование (разделы 1–8), (2) план, согласия, лист назначений, трансфузии (9–11, 13), (3) дневники и выписка (12).
2. `tools/prepare_case.py`: 3 документа, 8 096 знаков; ИИН и телефон закрыты автоматически, ФИО, дата рождения и адрес закрыты вручную.
3. Три агента этапов параллельно (каждый видит навык и только свой документ), затем агент свода (отчёты этапов и тексты документов для проверки цитат).
4. Выборочная проверка цитат основной сессией (поиск строк в `doc_NN.txt`): все проверенные цитаты найдены в указанных документах.

## Выводы

- Процесс работает: этапы честно оставляют своду выводы, требующие других документов, свод их закрывает и объединяет повторы (одна ошибка из трёх документов — одна находка).
- Результат совпал с лучшим одиночным прогоном (прогон 3) при том, что каждый агент видел только часть истории.
- Деление по типу документа внутри одной госпитализации искусственно; для реальных наборов делить по этапам (амбулатор, стационар 1, 2, выписки, протоколы).
