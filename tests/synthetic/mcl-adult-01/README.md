# Тест-кейс mcl-adult-01

Синтетическая история болезни мужчины 72 лет с рецидивом лимфомы из клеток мантии на ибрутинибе, внебольничной пневмонией и инвазивным аспергиллёзом: вориконазол назначен без снижения дозы ибрутиниба (носовое кровотечение, макрогематурия, фибрилляция предсердий), ривароксабан назначен при активном кровотечении, бронхоскопия с трансбронхиальной биопсией без паузы ибрутиниба (лёгочное кровотечение, ОРИТ), гидроксимочевина по ошибочному «прогрессированию» при лимфоцитозе, не исследованы галактоманнан, ЭхоКГ, калий и магний, выписка без лимфомы, статуса ибрутиниба и перечня взаимодействий. Все данные вымышлены. Кейс не использовался при настройке навыка (нозология новая; смежные кейсы `cll-adult-01`, `fl-adult-01`, `wm-adult-01`).

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: лимфома из клеток мантии, ибрутиниб и лекарственные взаимодействия (CYP3A4), геморрагический риск таргетной терапии, пауза перед процедурами, антикоагуляция при фибрилляции предсердий на ибрутинибе, лимфоцитоз на ингибиторе БТК; ловушки (ожидаемый лимфоцитоз, выбор вориконазола, антибактериальная терапия, переливание эритроцитов при кровотечении).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.0: 7 значимых (З1 №1–3; З2 №4–7) и 4 незначимые находки, ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 6 из 7, класс совпал не менее чем у 5 из 7, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
