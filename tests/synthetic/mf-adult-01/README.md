# Тест-кейс mf-adult-01

Синтетическая история болезни мужчины 63 лет с первичным миелофиброзом (JAK2 V617F, DIPSS промежуточный-2) на терапии ингибитором JAK (руксолитиниб): доза в листе назначений втрое выше плановой, тромбоцитопения до 22 без приостановки препарата, аспирин с носовым кровотечением, нет скрининга HBV и туберкулёза, взаимодействие с флуконазолом, антибиотик при лихорадке через 22 часа, выписка с возобновлением при тромбоцитах 31, консультация по ТГСК по плану не проведена. Все данные вымышлены. Кейс не использовался при настройке навыка.

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, расхождению плана и листа назначений и по отсутствию действия в листе.

Новое по сравнению с другими кейсами: миелофиброз (первичная Ph-негативная МПН, ингибитор JAK; ранее только полицитемия); дозирование по тромбоцитам и расхождение плана и листа (З1 при реализованном осложнении); продолжение препарата при тромбоцитах менее 50; противопоказанное назначение (аспирин при тромбоцитопении с кровотечением — правило из ИТП и Ph+ ОЛЛ); скрининг до ингибитора JAK; взаимодействие с азолом; задержка антибиотика на иммуносупрессии; выписка; ловушки (аспирин при 74, эритроцитная масса, цефтриаксон).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1–2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
