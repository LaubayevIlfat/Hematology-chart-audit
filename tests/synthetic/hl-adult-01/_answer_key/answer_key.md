# Ключ к тест-кейсу hl-adult-01 (НЕ загружать вместе с историей)

Синтетический случай: женщина 28 лет, классическая лимфома Ходжкина, нодулярный склероз, стадия IIB, bulky средостение 11 см (C81.1), ABVD. Осложнения: острая обструкция дыхательных путей при общей анестезии (экстренная интубация, ОРИТ около 18 ч), нейтропения 4 ст., блеомициновый пневмонит с гипоксемией. Исход: выписана с улучшением на Д+36 (нелетальный, раздел 5 не применяется). Д0 = 20.08.2026. Версия ключа 1.0. Кейс не использовался при настройке навыка; клинические ориентиры написаны автором и подлежат проверке гематологом.

## Не должно быть записано как дефект (ловушки)

- Выбор ABVD при стадии IIB с bulky средостением: допустим (альтернатива — эскалированные режимы, не обязательна); консолидирующая лучевая терапия на bulky запланирована: верно. Шесть циклов по плану допустимы.
- ЭхоКГ и ЭКГ до доксорубицина выполнены: верно. ПЭТ-КТ при стадировании выполнена: верно. Промежуточная ПЭТ-КТ после 2 циклов запланирована: верно.
- Дозы доксорубицина 42 мг (расчёт 42,5 мг), блеомицина 17 ЕД, дакарбазина 640 мг (расчёт 637 мг): верны, округление допустимо. Площадь тела 1,70 м² верна.
- Выбор гистологической верификации (диагноз лимфомы только по биопсии): верно; дефект только в способе (общая анестезия, находка №1).
- Тактика после пневмонита (отмена блеомицина, глюкокортикоиды, кислород, дальнейший AVD): верна.
- Трансфузии не требовались: верно. Антиэметики: верно.
- ПЭТ-КТ и стадирование по Анн-Арбор верны.

## Ожидаемая оценка тактики

Выбор линии и схемы верен; отклонения: задержка цикла при нейтропении без лихорадки (интенсивность дозы), Г-КСФ с блеомицином, расхождение дозы винбластина. Ожидаемо: *субоптимальна*. «Не соответствует» не ожидается. Дефекты сопроводительной терапии и анестезиологические решения в оценку тактики не входят.
