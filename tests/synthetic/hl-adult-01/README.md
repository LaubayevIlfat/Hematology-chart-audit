# Тест-кейс hl-adult-01

Синтетическая история болезни молодой взрослой пациентки с классической лимфомой Ходжкина (C81.1), стадия IIB, bulky средостение, ABVD, нелетальный исход. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: лимфома Ходжкина (ABVD), жизнеугрожающее осложнение при диагностической процедуре (биопсия средостения под общей анестезией при компрессии трахеи), лёгочная токсичность блеомицина и правила по Г-КСФ, задержка цикла при нейтропении, фертильность и беременность перед химиотерапией.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики («субоптимальна») и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
