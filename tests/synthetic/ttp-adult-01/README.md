# Тест-кейс ttp-adult-01

Синтетическая история болезни молодой женщины с иммунной тромботической тромбоцитопенической пурпурой (ТТП, M31.1), поражение ЦНС, почек, сердца, нелетальный исход. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: неотложная ситуация (микроангиопатия), задержка плазмообмена, противопоказанная трансфузия тромбоцитов с отделимым вредом (ишемические очаги через часы), ADAMTS13 до плазмы, объём плазмообмена, цитратная гипокальциемия, оценка миокарда при росте тропонина, критерии прекращения плазмообмена, беременность и вторичные формы.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики («субоптимальна») и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
