# Тест-кейс hs-child-01

Синтетическая история болезни мальчика 7 лет с наследственным сфероцитозом после лапароскопической спленэктомии: пенициллин после операции не назначен, менингококковая и Hib вакцины не введены, антибиотик при лихорадке у аспленика через 5 ч 30 мин (пневмококковый сепсис с септическим шоком и ОРИТ), не проведены прямая проба Кумбса и ЭМА-тест, тромбоциты 1120 без оценки риска, фолиевая кислота не назначалась, выписка без диагноза сфероцитоза и статуса аспленика. Все данные вымышлены. Кейс не использовался при настройке навыка (нозология новая; смежные кейсы `thal-child-01`, `aiha-adult-01`).

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: спленэктомия и профилактика постспленэктомического сепсиса (пенициллин, вакцины, карта аспленика), лихорадка у аспленика, предоперационный набор обследований при наследственном сфероцитозе; ловушки (показание к спленэктомии, бессимптомный камень, ПКВ13 вовремя, цефтриаксон и ОРИТ, ранняя выписка).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.1: 7 значимых (З1 №1, №2; З2 №3–7) и 4 незначимые находки, ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 6 из 7, класс совпал не менее чем у 5 из 7, детский профиль, нет утечек идентификаторов и выдуманных ссылок.

Решения эксперта после прогонов 1–3 внесены в ключ v1.1 и `comparison.md`.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке детским гематологом и хирургом.
