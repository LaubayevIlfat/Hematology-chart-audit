# Тест-кейс dlbcl-adult-01

Синтетическая история болезни взрослого пациента с ДВККЛ (C83.3), первый цикл R-CHOP-21, летальный исход на Д+13. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: лимфома (не лейкоз), летальный случай (раздел 5, статус «предварительное»), редукция доз по функции печени, коррекция по функции почек, реактивация HBV при анти-CD20, инфузионная реакция на ритуксимаб, сепсис и сроки перевода в ОРИТ.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых и 4 незначимые находки, ловушки, ожидаемый раздел 5. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, раздел 5 заполнен, статус «предварительное», нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ не править на основе этого кейса без отметки в `comparison.md` (иначе последующие прогоны перестают быть независимыми). Клинические значения подлежат проверке гематологом.
