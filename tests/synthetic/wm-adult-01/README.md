# Тест-кейс wm-adult-01

Синтетическая история болезни мужчины 70 лет с макроглобулинемией Вальденстрёма (IgM-каппа, MYD88 L265P+) и синдромом гипервязкости: ритуксимаб до плазмафереза и снижения IgM с вспышкой IgM и ишемическим инсультом, плазмаферез через 68 часов, эритроцитная масса до плазмафереза, бендамустин вдвое ниже дозы, ритуксимаб без премедикации с реакцией 3 степени, осмотр глазного дна через 4 суток, нет скрининга HBV, выписка с потерей варианта. Все данные вымышлены. Кейс не использовался при настройке навыка.

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей (IgM 74 и вязкость 7,9 после ритуксимаба), времени введения и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: макроглобулинемия Вальденстрёма (IgM-ассоциированный синдром гипервязкости, плазмаферез), IgM-вспышка после ритуксимаба (З1 при реализованном инсульте), порядок терапии (плазмаферез до ритуксимаба), противопоказанные эритроциты при гипервязкости, расхождение мг и мг/м² у бендамустина, скорость инфузии и премедикация ритуксимаба (правило о реакции), задержка осмотра глазного дна, скрининг HBV, выписка с потерей варианта; ловушки (плазмаферез как метод, схема бендамустин + ритуксимаб, МРТ).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1; З2 №2–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
