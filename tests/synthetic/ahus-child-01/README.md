# Тест-кейс ahus-child-01

Синтетическая история болезни девочки 6 лет с атипичным гемолитико-уремическим синдромом (тромботическая микроангиопатия, диализ-зависимое острое повреждение почек, масса 20 кг): тромбоцитарная масса при ТМА без показаний с судорогами и ишемическими очагами мозга, экулизумаб без антибиотикопрофилактики с менингококковым сепсисом, задержка старта препарата, доза 300 мг вместо 600 мг, введение до согласия, не выполнено обследование комплемента и шигатоксина, выписка без антибиотика и с диагнозом N17.9, поздняя гипотензивная терапия. Все данные вымышлены. Кейс не использовался при настройке навыка (нозология новая; смежный кейс `ttp-adult-01`).

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, времени записей и расхождению плана и листа назначений.

Новое по сравнению с другими кейсами: аГУС у ребёнка, терапия экулизумабом (вакцина, антибиотикопрофилактика, дозирование по массе), тромбоцитарные массы при ТМА, реализованное осложнение препарата (сепсис, З1), перекрёстные расхождения (время результата и записи, рост); ловушки (плазма как мост, вакцина и препарат в один день при антибиотике, лечение сепсиса).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — ключ v1.1: 7 значимых (З1 №1, №2; З2 №3, №4, №6, №7, №8) и 4 незначимые находки (№5, №10–12), ловушки, ожидаемая оценка тактики, системность, открытые вопросы. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 6 из 7, класс совпал не менее чем у 5 из 7, детский профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом и нефрологом.
