# Тест-кейс cll-adult-01

Синтетическая история болезни взрослого пациента с рецидивом хронического лимфолейкоза (C91.1) на таргетной терапии венетоклаксом, нелетальный исход. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: таргетная терапия (наращивание дозы венетоклакса, риск лизиса при низкой гидратации и ускоренных ступенях), аутоиммунная гемолитическая анемия, пропущенная до трансфузии (проба на совместимость, ДАТ), лекарственное взаимодействие с позаконазолом, облучённые компоненты после бендамустина, обследование перед линией (HBV, TP53 при рецидиве), ЭКГ при гиперкалиемии.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики («субоптимальна») и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8 (допустимо объединение №8 с №2), класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
