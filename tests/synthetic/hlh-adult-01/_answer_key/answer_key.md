# Ключ к тест-кейсу hlh-adult-01 (НЕ загружать вместе с историей)

Синтетический нелетальный случай: мужчина 34 лет, вторичный (ЭБВ-ассоциированный) гемофагоцитарный лимфогистиоцитоз, критерии выполнены с Д+1–Д+2, старт терапии с задержкой (Д+6), осложнения (гематома шеи после ЦВК без коррекции гемостаза, судорожный приступ, ОПП), этопозид без редукции при ОПП.
