# Тест-кейс hlh-adult-01

Синтетическая история болезни мужчины 34 лет с вторичным ЭБВ-ассоциированным гемофагоцитарным лимфогистиоцитозом: критерии HLH-2004 выполнены на Д+1, терапия начата на Д+6, гематома шеи после ЦВК без коррекции гемостаза, судорожный приступ, ОПП, этопозид без редукции, дексаметазон в половинной дозе. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: срочное неонкологическое состояние (ГЛГ), ожидание подтверждающего исследования как причина задержки лечения, инвазивные процедуры при коагулопатии, редукция этопозида при ОПП и гипербилирубинемии, занижение дозы дексаметазона, неполный поиск триггера (лимфома), профилактика ПЦП, нейровизуализация при судорогах, ловушки (sCD25 недоступен, ЛП не выполнена при тромбоцитах 36, ОРИТ в срок).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
