# Тест-кейс bl-child-01

Синтетическая история болезни мальчика 8 лет с лимфомой Беркитта (абдоминальная форма, стадия III) и высоким риском синдрома лизиса опухоли: цитостатик до расбуриказы и при заниженной гидратации (острое повреждение почек 3 стадии, ОРИТ, гемодиализ), расбуриказа без определения активности Г6ФД (гемолиз при дефиците), возрастная доза интратекального метотрексата завышена, люмбальная пункция при тромбоцитах 38, ибупрофен при ОПП, костный мозг 28% бластов без пересмотра группы риска, выписка с ибупрофеном и без отметки о Г6ФД. Все данные вымышлены. Кейс не использовался при настройке навыка.

**Формат.** История без раздела «Внутренние отметки»: находки выводятся только из записей истории; пропуски видны по значениям показателей, расхождению плана и листа назначений, времени введения и отсутствию действия в листе.

Новое по сравнению с другими кейсами: лимфома Беркитта и неонкологическая-подобная срочность (синдром лизиса с ОПП и гемодиализом); порядок профилактики (расбуриказа за 4 часа до цитостатика, З1 при реализованном осложнении); расбуриказа и Г6ФД; возрастная доза интратекального метотрексата (как в детском ОЛЛ); процедура при тромбоцитах ниже записанного порога; НПВП при ОПП; пересмотр группы риска по костному мозгу; выписка после синдрома лизиса; ловушки (расбуриказа вместо аллопуринола, гемодиализ, фуросемид, ликвор без бластов).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1; З2 №2–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, детский профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
