# Тест-кейс mm-adult-01

Синтетическая история болезни взрослой пациентки с множественной миеломой (C90.0), первая линия VCd, нелетальный исход (выписана с улучшением). Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: миеломная болезнь (плазмоклеточная дискразия), нефротоксичные воздействия при миеломной нефропатии (НПВП, контраст, бисфосфонат без расчёта клиренса), гиперкальциемия, нейропатия на бортезомибе и критерии редукции, противовирусная профилактика при протеасомных ингибиторах, стероидная гипергликемия, ресурсное ограничение (даратумумаб недоступен).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1, 2; З2 №3–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системности. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
