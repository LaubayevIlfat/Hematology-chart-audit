# Тест-кейс aml-adult-01

Синтетическая история болезни взрослого пациента с ОМЛ (NPM1+), индукция «7+3», смерть на Д+14. Все данные вымышлены.

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — заложенные находки (10 значимых, 4 незначимых), ловушки, ожидаемая оценка и системные цепочки. Не загружать вместе с историей.
- `run_01/`, `run_02/` — отчёты слепых прогонов навыка; `comparison.md` — сверка с ключом.

Критерий приёмки по PRD v0.6 (критерий 8): найдено не менее 8 из 10 значимых ошибок, нет выдуманных ссылок, нет утечки идентификаторов, ловушки не записаны как дефекты.
