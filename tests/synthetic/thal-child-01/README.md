# Тест-кейс thal-child-01

Синтетическая история болезни мальчика 11 лет с β-талассемией major (трансфузионно-зависимая, спленэктомия, хелаторная терапия деферазироксом): гастроэнтерит, лихорадка после спленэктомии, острое повреждение почек с тубулопатией на фоне продолжения деферазирокса. Все данные вымышлены. Кейс не использовался при настройке навыка.

Новое по сравнению с другими кейсами: доброкачественное трансфузионно-зависимое заболевание у ребёнка; токсичность хелатора (деферазирокс) при продолжении введения и неполное ведение ОПП; пересчёт дозы при смене лекарственной формы; лихорадка у аспленического пациента; трансфузионная безопасность (фенотип, антитела); ТГСК как излечивающий метод; ловушки (МРТ T2* 8 месяцев назад, вакцинация и пенициллин после спленэктомии).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1; З2 №2–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, детский профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.
