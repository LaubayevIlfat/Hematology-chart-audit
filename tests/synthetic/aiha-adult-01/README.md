# Тест-кейс aiha-adult-01

Синтетическая история болезни женщины 47 лет с впервые выявленной тяжёлой тёплой аутоиммунной гемолитической анемией (IgG): проксимальный ТГВ без тромбопрофилактики, преднизолон вдвое ниже плана, задержка трансфузии при ишемических изменениях на ЭКГ, ритуксимаб off-label без консилиума, в недозе (375 мг вместо 375 мг/м²) и до получения HBV-статуса (анти-HBc оказался положительным), гипергликемия без контроля, выписка без антикоагулянта. Все данные вымышлены. Кейс не использовался при настройке навыка.

**Формат.** История без раздела «Внутренние отметки» (как кейс scd-child-01): находки выводятся только из записей истории; явных записей об отсутствии действий почти нет, пропуски видны по значениям показателей, расхождению плана и листа назначений и по отсутствию действия в листе.

Новое по сравнению с другими кейсами: аутоиммунная гемолитическая анемия (ХЛЛ-кейс содержал только её фрагмент); тромбопрофилактика при гемолитической анемии с реализованным ТГВ (З1); недодоза стероида и ритуксимаба (расхождение плана и листа; расчёт по мг и мг/м²); off-label ритуксимаба без консилиума (правило из МДС); HBV-статус до ритуксимаба (результат получен после введения); задержка трансфузии при ишемии; выписка после ТГВ; ловушки (индивидуальный подбор при положительной пробе на совместимость, поиск вторичных причин как желательные обследования).

- `chart.md` — материал для аудита. Загружать в навык отдельно.
- `_answer_key/answer_key.md` — 8 значимых (З1 №1; З2 №2–8) и 4 незначимые находки, ловушки, ожидаемая оценка тактики и системность. Не загружать вместе с историей.

Критерий приёмки: найдено не менее 7 из 8, класс совпал не менее чем у 6 из 8, взрослый профиль, нет утечек идентификаторов и выдуманных ссылок.

Для сохранения независимости: после первого прогона навык и ключ по результатам этого кейса не править без отметки в `comparison.md`. Клинические значения подлежат проверке гематологом.

Версия ключа 1.1: после прогонов 1–3 внесены решения эксперта (тромбопрофилактика при АИГА, off-label ритуксимаб — З2); подробности в конце `_answer_key/answer_key.md` и в `comparison.md`.
