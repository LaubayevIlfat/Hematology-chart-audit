# Hematology chart audit

Навык Claude `hematology-chart-audit` для ретроспективного аудита историй болезни по гематологии (взрослые и дети до 18 лет, контекст РК). Аудит вспомогательный: заключение выносит врач-эксперт. Навык не назначает лечение и не ставит диагнозы.

## Состав репозитория

| Путь | Назначение |
|---|---|
| `PRD_v0.6.md` | Спецификация (при расхождении с навыком прав PRD) |
| `.claude/skills/hematology-chart-audit/SKILL.md` | Порядок работы (14 шагов), принципы |
| `.claude/skills/hematology-chart-audit/references/` | Обезличивание, разделы аудита, классификация З1/З2/Н, системность, структура отчёта, источники, нормативы РК, самопроверка |
| `templates/Shablon_zaklyucheniya_SPPVE.docx` | Шаблон заключения СППВЭ (не форма МЗ РК; ФИО, подписи, решение вносит человек) |
| `tests/synthetic/` | Пять синтетических кейсов с ключами и протоколами прогонов |
| `webapp/` | Исходник страницы Claude Artifact «Аудит истории болезни» (загрузка PDF, экспертиза, сохранение в Word) и скрипт сборки; см. `webapp/README.md` |

## Валидация

Метод: слепые прогоны субагентов. Агент читает только `chart.md`; ключ (`_answer_key`), прошлые прогоны и `comparison.md` ему запрещены. Отчёт сравнивается с ключом, результат дописывается в `comparison.md` кейса.

| Кейс | Ключ | Критерий приёмки | Последний результат |
|---|---|---|---|
| `aml-adult-01` (ОМЛ, взрослый) | v1.2, 10 значимых | найдено и класс ≥8/10 | прогоны 10–12: 10/10 найдено, 10/10 класс |
| `apl-adult-01` (ОПЛ, взрослый) | v1.1, 8 значимых | найдено ≥7/8, класс ≥6/8 | прогоны 1–3: 8/8 найдено; класс 6/8, 7/8, 8/8 |
| `all-child-01` (ОЛЛ, ребёнок 6 лет) | v1.1, 11 значимых | найдено ≥9/11, класс ≥8/11, детский профиль | прогон 3: 11/11 найдено, 11/11 класс (прогоны 1–2 на v1.0: 8/8 найдено, класс 7/8) |
| `dlbcl-adult-01` (ДВККЛ, взрослый, летальный) | v1.1, 11 значимых | найдено ≥9/11, класс ≥8/11, раздел 5, статус «предварительное» | прогоны 1–3: найдено 8/8 (по v1.1 пересчёт 11/11), 11/11, 11/11; класс 6/8 (пересчёт 8/11), 9/11, 11/11 |
| `mm-adult-01` (миелома, взрослая, нелетальный) | v1.0, 8 значимых | найдено ≥7/8, класс ≥6/8 | прогоны 1–3: 8/8 найдено в каждом, класс 7/8 в каждом (расхождение каждый раз по одному пункту: №8 кеторолак, №5 дексаметазон, №4 гиперкальциемия; после решений эксперта пункты закрываются, но проявляется следующая граничная зона) |

Подробности, расхождения и оговорки по каждому прогону: `tests/synthetic/<кейс>/comparison.md`.

Что проверено на разных кейсах: ОМЛ — лизис опухоли, антибиотик при фебрильной нейтропении, противогрибковая профилактика, QT; ОПЛ — коагулопатия, дифференцировочный синдром, задержка ATRA; детский ОЛЛ — возрастные дозы и нормы, расчёт по площади тела, токсичность аспарагиназы; ДВККЛ — летальный случай (раздел 5), редукция доз по функции органов, коррекция по почкам, HBV при анти-CD20, инфузионная реакция, сепсис и сроки перевода в ОРИТ; миелома — нефротоксичные назначения при миеломной нефропатии, гиперкальциемия, нейропатия на бортезомибе, противовирусная профилактика, стероидная гипергликемия, ресурсное ограничение (даратумумаб недоступен).

## Ограничения (читать перед использованием)

- **Независимость результатов неполная.** Правила навыка уточнялись по итогам прогонов, поэтому поздние прогоны на тех же кейсах частично подогнаны. Прогоны 10–12 по ОМЛ не считаются независимыми (в навык попали данные кейса, они затем удалены). Ключи кейсов ОПЛ, детского ОЛЛ и ДВККЛ менялись по решениям эксперта после первых прогонов, а правила навыка по этим решениям обновлялись; по затронутым пунктам поздние прогоны частично подогнаны. Кейс миеломы был первой независимой проверкой после настройки: пункты 1–3, 6 и 7 навык не менял и они верны во всех прогонах, пункты 4, 5 и 8 затронуты правками. По ДВККЛ пункты 2–7 ключа навык не менял, они стабильно верны во всех трёх прогонах. Для честной оценки нужны новые кейсы, не использовавшиеся при настройке.
- **Кейсы синтетические**, написаны автором навыка. Клинические значения в ОПЛ- и детском кейсах (гидратация, интратекальный метотрексат по возрасту, доза цефепима, возрастные нормы креатинина, срок ПЭГ-аспарагиназы) не проверены врачом-экспертом соответствующего профиля.
- **Источники не открывались.** В прогонах внешние источники (протоколы РК, ДСМ, BFM/COG, Cairo–Bishop, рекомендации по ФН) не были открыты полностью, поэтому клинические находки имеют уверенность «низкая», эталоны помечены «требует сверки». Протоколы РК и приказы ДСМ в рамках разработки не проверялись.
- **Справочник порогов** `references/thresholds.md` не заведён: числовые пороги добавляются только после экспертного подтверждения.
- Решения по классам (З1/З2/Н), зафиксированные в `classification.md`, принадлежат одному эксперту; при расхождении мнений правила пересматриваются. Граница З1/З2 для реализованных осложнений уточнялась по ходу: осложнение, прямо вызванное ошибкой действия, — З1; многофакторное осложнение при неполном ведении или противопоказанном назначении без отделимого вклада — З2; переписанная доза с ожидаемой токсичностью препарата — З2; обратимое ухудшение за время задержки эскалации при благоприятном исходе — З2. Граничные зоны проявляются в каждом новом кейсе: набор правил полным не считать.
- Источники, указанные агентами из PubMed (DOI и PMID), выборочно не сверены. Раздел 5 проверен на одном летальном кейсе; методика сопоставления с ПАО (ДСМ-259) в PRD остаётся открытым вопросом.
- Нелетальные случаи: раздел 5 не применяется. Летальные: статус «предварительное» до заключения ПАО. Пакетный режим на реальных данных не проверялся.

## Конфиденциальность

В отчёты и заключения допускаются только номер экспертизы, дата проверки, номер истории болезни. Даты событий заменяются на Д0/Д+N, пациент обозначается «Пациент А». Реальные истории болезни в репозиторий не загружать. Страница `webapp/` отправляет текст в Claude с аккаунта пользователя: перед использованием на реальных данных нужно проверить политику организации; закрытие идентификаторов на странице частичное, остальное закрывает пользователь.

2. Проверка клинических значений педиатром-гематологом и гематологом-экспертом (ОПЛ).
3. Сверка с открытыми версиями протоколов РК и приказов ДСМ; заполнение `thresholds.md`.
4. Решение эксперта по объединению находок разных препаратов и по сроку ПЭГ-аспарагиназы в детском кейсе; проверка клинических ориентиров ДВККЛ (редукция доксорубицина по билирубину, коррекция цефепима по клиренсу, интервал пегфилграстима, скорость возобновления ритуксимаба).
