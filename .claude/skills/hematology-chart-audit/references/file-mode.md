# Файловый режим: большие истории из нескольких документов

Использовать, когда набор документов одного пациента не помещается в страницу (лимит одного запроса 256 КиБ) или эксперт просит «аудит файлами». Лимит одного запроса здесь не действует: документы лежат файлами, аудит ведут агенты, читающие файлы по частям. Решения и правила те же (`classification.md` целиком, без отбора блоков).

## Конфиденциальность

- Реальные документы класть только в `cases/<имя>/` (папка в `.gitignore`, в GitHub не попадает) или в рабочую папку сессии; не коммитить, не вставлять в чат, не отправлять во внешние сервисы.
- Перед аудитом: `python3 tools/prepare_case.py cases/<имя>/in --out cases/<имя>/text`. Скрипт читает .docx, .pdf (нужен pdftotext), .txt, .md; закрывает ИИН, телефоны, почту, номера документов; убирает номера страниц, декоративные линии, длинные дословные повторы (заменяет пометкой); пишет `doc_NN.txt`, `all.txt`, `manifest.md` (имена файлов только в манифесте). ФИО, даты рождения, адреса, места работы автоматически не закрываются: открыть `doc_NN.txt` и закрыть вручную, затем напомнить эксперту, что исходные файлы остаются у него и в чате.
- Сканы и фото скрипт не читает: распознать отдельно, неразборчивое пометить `[нечитаемо]`.

## Порядок

1. **Состав.** Прочитать `manifest.md`; разбить документы на этапы (амбулаторный, стационар 1, стационар 2, выписки, протоколы исследований, ПАО). Неясное уточнить у эксперта. Правила амбулаторного этапа и стационара применяются каждое к своему этапу.
2. **Аудит этапов.** По одному агенту на этап (параллельно). Агент читает только файлы навыка и `doc_NN.txt` своего этапа (длинные файлы по частям, `offset` и `limit`), ничего не записывает. Вернуть: хронологию этапа (таблица, «док. N, Д…»), таблицу фактов (диагнозы и коды, препараты с дозой, путём и днями, масса и рост, ключевые лабораторные значения, согласия, явные записи об отсутствии), находки по правилам навыка с цитатой и номером документа, «Требует уточнения».
3. **Свод.** Агент или основная сессия получает отчёты этапов (не исходники) и: строит единую хронологию; сверяет документы между собой (диагнозы и коды, даты, дозы, масса, согласия, расхождения); объединяет повторные находки (одна ошибка из разных документов — одна находка); пересчитывает счётчик З1/З2/Н; делает системность, вопросы врачу, рекомендации, источники, проект заключения по `report-structure.md`.
4. **Проверка.** Каждая З1 и находка на сверке документов проверяется по цитате в `doc_NN.txt` (поиск строки); не подтверждённое цитатой снять или понизить с пометкой.
5. **Выдача.** Приложение 1 и проект заключения сохранить в `cases/<имя>/report/` (папка не коммитится); эксперту выдать краткое резюме без идентификаторов и файл.

Если весь набор укладывается примерно в 150 тысяч знаков, достаточно одного агента на весь набор без этапов 2–3.

## Шаблон задания агенту этапа

```
Ты выполняешь аудит этапа «<название>» истории болезни по гематологии по навыку hematology-chart-audit.
Читай только файлы навыка (<путь>/.claude/skills/hematology-chart-audit/SKILL.md и references/) и файлы этапа: <doc_NN.txt …>. Другие файлы не открывай.
Верни текстом (файлы не записывай): 1) хронология этапа (таблица, ссылки «док. N, Д…»); 2) таблица фактов; 3) находки по правилам навыка с классами З1/З2/Н, кодом ЕК ФСМС (ориентир), цитатой записи и номером документа, эталоном, влиянием, уверенностью; 4) «Требует уточнения».
Идентификаторы не переносить, календарные даты заменять на Д±N (Д0 — поступление в этот этап; для связи этапов укажи интервал до Д0 основного эпизода, если он известен).
```

## Шаблон задания агенту свода

```
Ты сводишь аудит нескольких этапов одной истории болезни по навыку hematology-chart-audit. Ниже отчёты этапов; исходные документы: <doc_NN.txt …> (для проверки цитат).
Построй единую хронологию; сверь документы между собой; объедини повторные находки; пересчитай счётчик З1/З2/Н; выполни системность, вопросы врачу, рекомендации, источники и проект заключения по references/report-structure.md. Каждую З1 подтверди цитатой из документа. Идентификаторы не переносить.
```
