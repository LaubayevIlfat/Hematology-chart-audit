# Анализ системности ошибок (FR-5а)

Обязательный блок отчёта, после сводной таблицы находок.

1. **Группировка по первопричине**, а не по месту обнаружения. Примеры: недооценка риска (инфекция, лизис опухоли), отсутствие протокола или чек-листа, задержка эскалации, ошибка расчёта дозы, разрыв передачи информации между сменами, ресурсные ограничения.
2. **Цепочки ошибок:** находки, усиливавшие друг друга (например: поздний антибиотик → сепсис → поздний перевод в ОРИТ → смерть). Для каждой цепочки — звено, где развитие можно было прервать.
3. **Повторяемость:** единичная или систематическая (в нескольких циклах, днях, назначениях). По одной истории указывать «признаки возможной системности».
4. **Влияние на исход:** повлияла / вероятно повлияла / риск без реализации / не влияет — с обоснованием.
5. **Уровень причины** (единая шкала с шаблоном заключения): *врач* (индивидуальное решение); *отделение* (процесс: нет регламента или чек-листа); *организация* (нагрузка, кадры, логистика); *ресурсы* (препарат, метод, диагностика).
6. **Рекомендации по устранению причины**, а не только по исправлению записи.
7. **Пакетный режим:** те же показатели по набору случаев — какие причины повторяются чаще и какие чаще ведут к значимым последствиям.

Таблица системных причин: корневая причина · уровень · повторяемость · связь с исходом · связанные находки (коды).
