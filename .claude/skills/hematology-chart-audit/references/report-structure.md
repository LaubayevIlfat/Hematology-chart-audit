# Структура отчёта и заключения (FR-6, FR-6а)

Итог — один компактный документ: заключение по шаблону СППВЭ (`templates/Shablon_zaklyucheniya_SPPVE.docx`) со встроенными итогами аудита и короткое приложение. Отдельного длинного аналитического отчёта нет: всё, что раньше дублировалось (шапка, резюме, подробные находки, системность, рекомендации), живёт в заключении один раз. Форма внутренняя, не утверждена МЗ РК, не относится к формам ДСМ-175/2020. Цель: сократить объём (заключение около 2 страниц А4) без потери информативности и наглядности: таблицы, отметки ☒/☐, коды-метки З1/З2/Н.

## Порядок выдачи (единый документ)

1. **Заключение внутренней экспертизы** (шаблон СППВЭ), разделы:
   - **1–2. Реквизиты и сведения о случае** — одна таблица (номер, дата и эксперт — для человека; основание и вид материалов; код дела, № истории, возраст и пол, профиль ☒, диагноз и МКБ-10, этап ☒, период в «Д0…», исход ☒);
   - **3. Итоговая оценка тактики** — одна строка отметок (оптимальна / приемлема / субоптимальна / не соответствует) и обоснование 2–4 предложения;
   - **4. Выявленные дефекты** — счётчик «З1 · З2 · Н» и ОДНА таблица всех находок (код · раздел · дефект: что, где (день), эталон · влияние на исход · код ЕК ФСМС): первые не более 5 строк — ключевые (★, подробно), остальные З2 и Н — одной строкой, Н группируются по темам;
   - **5. Системные причины** — таблица до 5 строк (причина · уровень · повторяемость · связь с исходом · коды) и одна строка с цепочкой ошибок;
   - **6. Летальный исход** — только при смерти, компактная таблица с отметками;
   - **7. Решение и рекомендации** — проект ИИ (отметки и по 1–3 действия врачу, отделению, организации, срок контроля); эксперт-человек дополняет сам;
   - **8. Подписи** — заготовка для человека.
2. **Приложение** (короткое): сокращённая хронология (до 12 строк, ключевые события и интервалы), сверка документов (при нескольких документах), аудит по разделам 1–4 (и 5) в виде таблицы «раздел · соответствует · коды находок», альтернативные методики (только если есть); основание экспертизы (одной строкой — использованные блоки базы); оговорка «Отчёт носит вспомогательный характер. Итоговое заключение выносит эксперт».
3. **Вопросы лечащему врачу и к своду** — самым последним разделом, только по клинически значимым неясностям.
4. Краткое резюме (до 25 строк, без идентификаторов) — только для чата, в документе не показывается.

Несколько пациентов (пакет): вверху оглавление пакета (таблица историй со счётчиками З1/З2/Н), затем заключения разных пациентов строго раздельно, каждое под своей плашкой «ИСТОРИЯ k ИЗ N · № истории болезни · документы», номер экспертизы с суффиксом /k; данные разных пациентов не смешиваются.

Не дублировать: описание находки пишется один раз (в таблице раздела 4); в приложении только ссылки на коды. Страница строит документ из двух запросов: рабочие данные аудита (шапка, оценка, хронология, аудит по разделам, находки, реестр) и итоговое заключение; из рабочих данных в документ переносятся только хронология, сверка, аудит по разделам и альтернативные методики.

## Заключение: что заполняет навык

| Раздел шаблона | Кто |
|---|---|
| 1. Реквизиты | Номер экспертизы — навык или человек; дата проверки — только человек (в отчёт не вносится); ФИО эксперта — только человек |
| 2. Сведения о случае | Навык (проект): код дела, № истории болезни, возраст и пол, профиль, диагноз и МКБ-10, этап лечения (диагностика / индукция / консолидация, поддержка / рецидив, рефрактерность / ТГСК / паллиативный / иное), период, исход |
| 3. Итоговая оценка тактики | Навык предлагает, эксперт подтверждает |
| 4. Дефекты | Навык (проект): счётчик З1/З2/Н и не более 5 ключевых дефектов — сначала все З1 по тяжести влияния, затем З2 по вероятности влияния; у каждого дефекта отдельной колонкой (или в конце строки) «Код ЕК ФСМС (ориентир)»; остальное в Приложении 1 |
| 5. Системные причины | Навык (проект) |
| 6. Летальный исход | Навык (проект); статус «предварительное» по умолчанию |
| 7. Решение и рекомендации | Навык (проект): предлагает решение по итоговой оценке тактики и рекомендации врачу, отделению, системе; эксперт-человек дополняет |
| 8. Подписи, ознакомление, возражения, ФИО эксперта | Только человек |

Счётчик З1/З2/Н в заключении должен совпадать с отчётом.

## Формат вывода

- Документ Word: использовать навык `docx` для сборки. Заключение — копия шаблона с заполненными разделами 1 (кроме ФИО) – 7.
- В чате: краткое резюме без идентификаторов.
- Перед выдачей проверить: нет ФИО, ИИН, дат рождения, телефонов, адресов; у каждой находки есть код, запись, эталон, влияние, уверенность; основание и оговорка перед вопросами; вопросы — в самом конце.
