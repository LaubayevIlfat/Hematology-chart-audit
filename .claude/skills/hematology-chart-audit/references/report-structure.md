# Структура отчёта и заключения (FR-6, FR-6а)

Итог — два уровня: одностраничное «Заключение внутренней экспертизы» (`templates/Shablon_zaklyucheniya_SPPVE.docx`) и аналитический отчёт Word (Приложение 1). Форма внутренняя, не утверждена МЗ РК, не относится к формам ДСМ-175/2020.

## Приложение 1. Аналитический отчёт (Word)

0. **Срочный блок** — только если случай текущий и есть угроза жизни.
1. Шапка: код дела, возраст и пол, профиль, диагноз, исход, период в «Д0…», доступные материалы и качество чтения. Допустимые реквизиты: номер экспертизы, № истории болезни; дата проверки не вносится (поле для человека).
2. Краткое резюме (4–6 предложений) и счётчик «З1 / З2 / Н».
3. Хронология (таблица).
4. Разделы 1–4 (и 5 при летальном исходе): что соответствует, находки, требует уточнения.
5. Сводная таблица находок с классами и анализ системности ошибок.
6. Альтернативные методики (таблица) и итоговая оценка тактики.
7. Вопросы лечащему врачу (что нельзя заключить по документам).
8. Рекомендации: врачу, отделению, системе.
9. **Источники** (в самом конце): название, год и редакция, пункт или раздел, ссылка, статус проверки.
10. Ограничения аудита и оговорка: «Отчёт носит вспомогательный характер. Итоговое заключение выносит эксперт».

## Заключение: что заполняет навык

| Раздел шаблона | Кто |
|---|---|
| 1. Реквизиты | Номер экспертизы — навык или человек; дата проверки — только человек (в отчёт не вносится); ФИО эксперта — только человек |
| 2. Сведения о случае | Навык (проект): код дела, № истории болезни, возраст и пол, профиль, диагноз и МКБ-10, этап лечения (диагностика / индукция / консолидация, поддержка / рецидив, рефрактерность / ТГСК / паллиативный / иное), период, исход |
| 3. Итоговая оценка тактики | Навык предлагает, эксперт подтверждает |
| 4. Дефекты | Навык (проект): счётчик З1/З2/Н и не более 5 ключевых дефектов — сначала все З1 по тяжести влияния, затем З2 по вероятности влияния; остальное в Приложении 1 |
| 5. Системные причины | Навык (проект) |
| 6. Летальный исход | Навык (проект); статус «предварительное» по умолчанию |
| 7. Решение и рекомендации | Только человек |
| 8. Подписи, ознакомление, возражения | Только человек |

Счётчик З1/З2/Н в заключении должен совпадать с отчётом.

## Формат вывода

- Документ Word: использовать навык `docx` для сборки. Заключение — копия шаблона с заполненными разделами 1 (кроме ФИО) – 6.
- В чате: краткое резюме без идентификаторов.
- Перед выдачей проверить: нет ФИО, ИИН, дат рождения, телефонов, адресов; у каждой находки есть код, запись, эталон, влияние, уверенность; источники в конце.
